# Understanding-AI-Adoption

## Interactive dashboard

The Streamlit dashboard explores survey response distributions and the
relationships between AI knowledge, trust, perceived risks, AI product use,
and willingness to adopt. It also compares descriptive results by age,
education, and employment status.

Run locally with Python 3.10 or newer:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

To deploy on [Streamlit Community Cloud](https://share.streamlit.io/), select
this repository, the `main` branch, and `app.py` as the main file. The app
shows aggregate statistics only. Results are exploratory and should not be
interpreted as causal or representative of the general population.
